# Web Portofolio (slide per slide)

Static site, tanpa build. Deploy langsung ke Vercel.

## Edit konten
Buka `https://domainmu.vercel.app/#edit` (sekali saja, tombol ✎ Edit akan muncul di browsermu).
Data tersimpan di browser. Supaya tampil untuk semua pengunjung: klik **Export**, lalu taruh `data.json` di root repo, commit, push.

## Deploy
1. Push repo ke GitHub
2. vercel.com > Add New > Project > pilih repo > Deploy (Framework: Other, tanpa build command)
